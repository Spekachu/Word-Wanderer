# Word Wanderer - Frontend

## Project Overview

Word Wanderer is an interactive language learning tool designed to enhance vocabulary acquisition through visual representation. This repository contains the frontend code for the Word Wanderer project.

The app presents words in an interactive, map-like interface, allowing users to explore vocabulary across different languages, proficiency levels, and parts of speech. Users can personalize their learning experience by associating words with emojis and custom color highlighting.

## Key Features

- Interactive word map with draggable and zoomable interface
- Support for multiple language pairs
- CEFR level filtering (A1-C2)
- Part of speech categorization
- Personalized word associations with emojis and color highlighting
- User authentication and progress saving

## Technologies Used

- **React.js**: For building the user interface
- **React Router**: For handling navigation within the app
- **Context API**: For state management
- **Tailwind CSS**: For styling and responsive design
- **i18next**: For internationalization support

## Project Structure

The project follows a standard React application structure, with key directories including:

- `/src/components`: React components
- `/src/contexts`: Context providers for state management
- `/src/pages`: Main page components
